NEON COAST COVER STUDIO turns your photos and a caption into a multi-panel GTA-style poster cover with six layouts, six sunset and neon grades, a halftone title block, a heat meter, and a badge ribbon, then exports it as a PNG in 1080 x 1080, 1080 x 1350, 1920 x 1080, or a 1080 x 1920 story format. Built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

The app then opens at <http://localhost:8080>.
